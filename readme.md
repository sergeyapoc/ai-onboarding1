# AI Onboarding — Core Building Blocks

Practical implementation of foundational AI engineering concepts:
- **`main.py`**: Prompt engineering and LLM API integration (Groq).
- **`embeddings_demo.py`**: Semantic search using text embeddings (`fastembed`).
- **`simple_agent.py`**: Basic AI agent with tool calling and reasoning loop.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Create a `.env` file and add `GROQ_API_KEY=your_key`
